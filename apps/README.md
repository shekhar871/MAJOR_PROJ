# PocketBridge Client Applications

This folder contains the three client surfaces that interface with the PocketBridge local REST API:
1. `apps/mobile/` - React Native Expo companion app with QR pairing scanner and document upload.
2. `apps/desktop/` - Electron + React lightweight dashboard showcasing pairing QR and file inbox.
3. `apps/cli/` - Node.js terminal client demonstrating CLI status and tasks commands.
